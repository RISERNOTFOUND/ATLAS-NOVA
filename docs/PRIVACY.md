# Privacy

Everything is stored locally on the machine running the bots; there is no telemetry. Outbound connections (from the code): Discord; RSS/YouTube/Twitch (only if feeds are configured); Hugging Face (Piper voices, first run); gyan.dev (FFmpeg download, Windows setup); your own LM Studio at `AI_BASE_URL` (default localhost, only if AI is on).

Stored: per-server settings, member IDs for warnings/cases/notes/tickets/reminders/birthdays/AFK, activity statistics (counts and voice time, not message text), optional audit logs (message text only if "Include message text" is enabled), ticket transcripts (to staff log channel + opener DM).
Sensitive features: **DM forwarding** — **OFF by default**; it turns on only if you set `DM_FORWARD_CHANNEL_ID`. When on, every DM sent to ATLAS while it is online is copied to that server channel with the sender's username, user ID, timestamp, message text (up to ~3,800 characters) and attachment links, and ATLAS adds a ✅ reaction to the DM. Anyone who can read that channel can read those DMs, and Discord retains the copy. Keep the channel staff-only, tell users their DMs are reviewed, and keep the channel's retention to what you need. `!dmforwardtest` checks the setup, **`!visibility`** (DMs an admin recent messages the bot can read), **local AI** (message text goes to your LM Studio). Members can opt out of some features with `!prefs`. Delete data by removing the runtime files above. As operator you are responsible for complying with Discord's terms and local privacy law.
